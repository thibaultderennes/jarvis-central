Privacy

Last updated 21 October 2026.

This website

This page and the home page are static files. They set no cookies, run no scripts and load nothing from other sites: no analytics, no pixels, no ads.

The site is hosted by Vercel. Like any web host, Vercel keeps short-lived request logs (IP address, browser user agent, the page asked for) to run and protect the service. We don’t use those logs for anything else. Vercel’s own terms and privacy policy apply to them.

The Sentient Dash tool

Sentient Dash is software you install and run yourself. There is no Sentient Dash account and no central server: we never receive your data. When you run it, your data goes to services you choose and own:

  • Your database and website (Neon and Vercel, on your accounts): checklists, todos, plans, reviews, and summaries and short quotes of your own messages from Claude Code sessions.
  • Anthropic, through your own Claude plan: the worker and the Monday reviews send prompts to Claude, including excerpts of your session transcripts for the coaching review. Anthropic’s terms for your plan apply.
  • GitHub: build runs push branches and open pull requests on your repositories; skill packs are downloaded from public repositories.
  • Google or Apple calendars, if you connect them, and any metrics sources you configure.

Your project folders and full Claude Code transcripts stay on your Mac. The full list, and how to turn each part off, is in the security and privacy notes.

Removing it

The uninstall steps remove the worker and list what to delete on each service.
