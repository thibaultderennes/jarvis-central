Run all your projects from one private dashboard

Sentient Dash plans your week across every project folder, and Claude Code builds checklist items into pull requests you merge.

Install from GitHub How it works

Who it’s for

For a solo founder running several projects with Claude Code, who wants one answer each week: which project gets the time, and what to do next.

Your projects stay where they are

Every folder in your projects folder is a project. Each has a CLAUDE.md and a PRD.md with dated milestones; setup drafts them where they’re missing.

Built for one person

There are no seats, roles or shared projects. It runs on your Mac for you, and the site behind your password is yours alone.

What it does

A private website for planning and reviewing, and a worker on your Mac that does the work with Claude Code.

Hand work to Claude Code

  1. You set an item to in progressOr leave a message in the inbox, from your phone or your laptop.
  2. The worker on your Mac picks it upIt runs Claude Code inside that project and answers in the thread, or builds on a new branch.
  3. Claude opens a pull requestEach project picks a build mode: quick and direct, or with extra skills for tests, code review and docs.
  4. You approve and merge, or send it backNothing merges until you click. The worker never deploys, pays or messages anyone.

Plan the week

  • A checklist for every project folder, with deadlines read from each PRD’s milestones.
  • A Sunday planner that fits next week around your appointments and writes focus blocks into Google or Apple Calendar. It never moves your meetings.
  • Today, Week and a timeline across all projects, with your calendar beside your todos.

Get reviewed every Monday

  • Advisor reviews written by Claude in the role of a CEO, a CMO and a product owner on each active project: what shipped, what slipped, the risks and your top 3.
  • Screenings on demand for generic AI-made design, website pre-launch, and rights and compliance (a checklist Claude runs, not legal advice).
  • Proposed tasks go to the checklist in one click.

Keep the rest in order

  • Plan this project: Claude reads a folder and fills its checklist with what has to happen next.
  • Website builds: Claude builds a project’s site from its docs on a branch, with screenshots in the pull request.
  • Finance: recurring costs and unit economics per project, next to product metrics and daily stats.
  • A privacy guard: git hooks that block a commit or push containing your details or secrets.
  • Sign-in with a password and a 6-digit code from your authenticator app.
  • A ⌘K palette and keyboard shortcuts across the site.

3 accounts, all of them yours

Set it up in one Claude Code session

Claude does the setup with you. It takes about 30 to 45 minutes, most of it reviewing the PRDs it drafts.

Install from GitHub

You need a Mac, Node 20 or later, git, Claude Code signed in and a Vercel account; the Neon database is added from Vercel. GitHub CLI is optional, for pull requests.

  1. Clone the repo and start Claude Code

    $ git clone https://github.com/thibaultderennes/jarvis-central.git
$ cd jarvis-central
$ claude

  2. Ask Claude to set it up

    Set up Jarvis Central.

    Claude follows SETUP.md phase by phase: it checks your Mac, asks where your projects live, drafts any missing CLAUDE.md and PRD.md, deploys your site, connects your calendars and installs the schedules. Anything with a password or a secret, you type in your own terminal.

  3. Sign in and send a first message

    Sign in with your password and authenticator code, then ask the inbox “What should I do first tomorrow?”. The worker on your Mac answers within a minute or two.

Questions

What does it cost?
Sentient Dash is free and open source. You pay for your own Claude plan, which the worker uses through the claude CLI, so nothing is billed per message. The free tiers of Vercel and Neon are enough for one person.
Where does my data live?
In your Neon database, read by your site on your Vercel account. Your project folders and full Claude session transcripts stay on your Mac; prompts go to Claude on your own plan (what goes where). Calendar links and secrets are kept out of git by a privacy guard.
What do I need?
macOS, Claude Code signed in, Node 20 or later, git, a Vercel account and a Neon database. GitHub CLI if you want Claude to open pull requests.
Does Claude merge or deploy on its own?
No. It builds on a branch and opens a pull request. It merges only after you click Approve & merge, and it never deploys, pays or messages anyone.
Does it run on Linux or Windows?
The schedules use launchd on macOS. Linux works with cron (see agent/README.md in the repo). Windows isn’t supported.
Is there a hosted version?
Not today. You run your own copy on your own accounts.
Why does the repo say Jarvis Central?
That’s the working name the repository and its command line keep. Sentient Dash is the product, and it’s the name your site shows.
How do I suggest a change?
Open an issue on GitHub. Ideas come in as issues; pull requests from other accounts are closed automatically.
