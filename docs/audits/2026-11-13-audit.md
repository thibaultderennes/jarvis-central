**NEW (3).**
- **H 3.5** (HIGH) — the agent API's `PUT kv` takes any key (`app/app/api/agent/[...path]/route.ts:304`), and the new
  logout revocation keeps its state in exactly that table (`app/lib/sessionEpoch.ts:6`, key `session.epoch`). A token
  holder can therefore rewind the epoch and revive a cookie the owner logged out, or set a value no cookie matches and
  lock the owner out of the site until they sign in again. The control added for H 3.1 has no reserved-key guard.
- **H 8.1b** (LOW) — the new deny-list is narrower than the paths that matter: `agent/claude.mjs:10-11` lists `**/.env`,
  `**/.env.local`, `**/.env.*.local` and `**/.env.production`, so `.env.development`, `.env.staging`, `.envrc`,

  non-build run keeps `Bash(git show:*)` outside it (`agent/advisors.mjs:21`, `agent/weekly.mjs:42`).
- **H 8.2b** (LOW) — only the CLI enforces "in progress is the owner's go". The API still accepts
