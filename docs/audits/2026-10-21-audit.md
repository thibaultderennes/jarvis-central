# Audit 2026-10-21 (main @ 0cd416a, v0.7.4.9)

**0 critical, 6 high, 16 low** (SUED: 0 / 0 / 4; HACKED: 0 / 6 / 12). First report, so there is no diff yet: every FAIL
below is NEW. Both prompts from [`PROMPTS.md`](PROMPTS.md) were run read-only; the "known and intentional" list was
applied. Nothing is reachable without signing in and no secret was ever committed (all 86 commits checked).

Two statements in the docs are out of date and were read with the code as the truth: `PROMPTS.md` says there is "no
public content", but `site/` is now a public page (so SUED privacy and content checks apply to it), and
`docs/security.md` says "Nothing is ever merged", while the worker merges a PR after the owner presses merge.
