- **H 9.9** — `npm audit --omit=dev` reports **1 critical, 1 high** for `next@16.3.6` (`app/package.json:17`). It is
  rated HIGH here, not CRITICAL, because every pre-auth path in that band needs a second thing this repo does not
  ship, each checked individually: the unauthenticated image-optimisation RCE (GHSA-2464-fhr4-w9xw) is fixed by
  `sharp` ≥ 0.35.5 and the lockfile pins exactly 0.35.5 (`app/package-lock.json`, `node_modules/sharp` 0.35.5); SVG
  optimisation is gated on `images.dangerouslyAllowSVG` (`node_modules/next/dist/server/image-optimizer.js:1107`),
  which `app/next.config.ts` never sets; the image SSRF (GHSA-cjq9-62q9-8jv4) needs a remote host and
  `remotePatterns` defaults to `[]` (`node_modules/next/dist/shared/lib/image-config.js:69`); the `use cache` RCE,
  draft-mode leak and cache leak (GHSA-673q, GHSA-3w37, GHSA-h694) need `use cache`, which `grep -rn '"use cache"' app`
  does not find; the SSG/ISR cache-poisoning pair (GHSA-4jqv, GHSA-mcj8) needs prerendered pages, and `npx next build`
  marks every page and route dynamic except `/_not-found`, `/login` and the two icon routes; the MCP disclosure
  (GHSA-39w2) is the dev server only. It stays rank 1 all the same: it is a one-line bump, `/_next/image` is already
  outside the session proxy (`app/proxy.ts:14`), adding `images.remotePatterns` or `dangerouslyAllowSVG` later would
  turn it critical with no further warning, and until it is bumped `npm audit` reads "1 critical", which is what the
  PRD's 1.0 gate is measured on.
- **H 1.5** — the missing `server-only` guard is not only theory: after `npx next build`, the
  `@neondatabase/serverless` driver is in a 141 KB client chunk (`.next/static/chunks/1m8_-hdx41l_e.js`), pulled in by

  finds nothing, so nothing leaks — the driver just ships to the browser for no reason.
