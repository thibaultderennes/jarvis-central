# VibeCoded Screening: checklist

Research date: 2026-10-05. Aim: flag the tells that make a web project read as generic / AI-generated, so the founder can make deliberate choices instead.

## How to run it

- **Scope**: `app/**`, `src/**`, `pages/**`, `components/**`, `styles/**`, `public/**`, `index.html`, `tailwind.config.*`, `globals.css` / `index.css`, `components.json`, `package.json`, `README.md`, `content/**` (md/mdx/json copy).
- **Exclude**: `node_modules`, `.next`, `dist`, `build`, lockfiles, `components/ui/**` *only* when checking copy (that folder matters for the shadcn checks).
- **Grep**: patterns are ERE for `rg -n -i` / `grep -rEin`. Inside the tables `\|` means a regex alternation `|`.
- **Judge column**: `code` = decidable from the repo alone; `visual` = needs a screenshot of the rendered page (desktop + 390px mobile, light + dark); `both` = code finds candidates, a screenshot confirms.
- **Scoring rule** (from every source): one tell on its own is fine. The problem is **clustering**. Report a count per category and call the site "vibe-coded" when roughly 8+ high/med tells co-occur, especially in the hero.
- **Severity**: high = a layperson notices it / it's one of the top-cited tells; med = designers and devs notice it; low = craft polish.

## Visual-only vs code

- **Code is enough** for most checks (fonts, gradients, shadcn tokens, copy greps, meta, deps, fake trust).
- **Needs a screenshot** to confirm: `no-real-product-shot`, `ai-generated-art`, `low-contrast-text` (or an axe run), `permanent-dark-mode` (rendered result), `colored-glow-shadows`, `grain-over-gradient`, `tasteful-default-2`, `centered-hero` composition, `inconsistent-spacing` and `design-drift` (rendered rhythm), `weightless-headline` (human judgement on whether copy is specific).
- Suggested run: grep pass first (cheap), then one desktop + one 390px screenshot of `/` and one inner route in light and dark, then a human-style read of the hero copy.

## Owner seed list mapping

purple-to-blue gradient → `purple-blue-gradient`; gradient hero text → `gradient-hero-text`; emojis in headings → `emoji-headings`; Inter everywhere → `inter-everywhere`; coloured-border cards → `colored-border-cards`; glassmorphism → `glassmorphism`; low-contrast dark mode → `low-contrast-text` + `permanent-dark-mode`; 3 icon boxes → `three-icon-cards` + `icon-in-square`; badge above headline → `badge-above-headline`; lucide everywhere → `lucide-everywhere`; untouched shadcn → `untouched-shadcn`; fade-in on scroll → `fade-up-everything`; cursor-following beam → `cursor-beam-spotlight`; buttons fade on hover → `hover-fade-buttons`; inconsistent spacing → `inconsistent-spacing`; em dashes → `em-dash-density`; generic buzzwords → `buzzword-cluster`; serif italic accents → `serif-italic-accent`; Space Grotesk + Instrument Serif → `trendy-font-pair`; grain over gradient → `grain-over-gradient`.

Total: 68 checks (the 20 seed tells map onto 21 of them; 47 added). If 35-50 is a hard cap, the low-severity ones (`pure-black-white`, `title-case-headings`, `numbered-steps`, `uniform-section-padding`, `fake-window-chrome`, `count-up-stats`, `marquee-logos`, `bounce-pulse`, `rounded-2xl-shadow`, `exclamation-hype`, `scaffold-leftovers`, `giant-dep-kit`) can be folded into a single "polish" pass.

## Caveats

- The detection thresholds (counts per page, "8+ tells") are judgement calls, not from a study. Sailop's slop scores and the "~83% fade-up" figure are a vendor's own numbers; treat as directional.
- Font names and shadcn default token values shift between versions (shadcn v3 HSL vs v4 OKLCH). Diff against the version in the repo's `components.json` rather than trusting the literals above.
- The em dash, Inter, shadcn and lucide are all legitimate choices; flag them only as part of a cluster, and say so in the report.
